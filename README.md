# 日下部税理士事務所 ホームページ

茨城県水戸市の日下部税理士事務所の公式ホームページです。
WordPress を使わず、**HTML / CSS / 最小限の JavaScript** だけで作られた静的サイトで、
GitHub Pages でそのまま公開できます（年間の保守費用がかかりません）。

サイト URL（予定）: https://kskac.jp

---

## 📁 ファイル構成（5ページ）

```
homepage/
├── index.html          … ホーム（キャッチ・お知らせ・事務所メッセージ・サービス・アクセス・無料相談）
├── about.html          … 事務所紹介（代表挨拶・代表/税理士プロフィール・業務内容・アクセス）
├── services.html       … サービス・料金（税務会計顧問／財務コンサル／相続税申告・相続対策、料金表すべて）
├── faq.html            … FAQ（一般編・税務会計編・相続編）
├── contact.html        … お問い合わせ（フォーム・本契約の締結・プライバシーポリシー・アクセス）
├── 404.html            … ページが見つからないときの画面
├── css/style.css       … デザイン（色・文字・レイアウト）はここに集約
├── js/main.js          … メニュー開閉などの最小限の動き
├── assets/             … 画像置き場（代表写真などを入れます）
├── favicon.svg         … ブラウザのタブに表示されるアイコン
├── robots.txt / sitemap.xml … 検索エンジン向けの設定
└── README.md           … このファイル
```

> このサイトには **事業承継税制対応・建設業許可・採用情報** のページは含めていません
> （元サイトには存在しますが、今回の掲載対象外）。

## ✏️ 内容を更新したいとき（Claude Code への頼み方）

自然言語でお願いするだけで更新できます。例：

- 「**サービス・料金の相続税ライトプランを 220,000円から 250,000円に変更して**」
- 「**お知らせを新しい日付の内容に差し替えて**」
- 「**代表の写真を assets/daihyo.jpg として入れたので表示して**」
- 「**FAQに新しい質問と回答を追加して**」
- 「**サイト全体の色をもう少し落ち着いた青に変えて**」

自分で直す場合：本文は各 `.html` の日本語をそのまま書き換え、色やフォントは
`css/style.css` 先頭の「**1. デザイントークン**」の `:root` を編集します。

## 📨 お問い合わせフォームの設定

静的サイトには「送信を受け取る仕組み」がないため、外部サービスと連携します。
**Formspree（無料）** が簡単です。

1. https://formspree.io にアクセスし、メールアドレス（例：yukihiro@kskac.com）で登録
2. 新しいフォームを作成 → `https://formspree.io/f/xxxxxxxx` という送信先 URL が発行されます
3. `contact.html` の `<form action="https://formspree.io/f/your-form-id" ...>` の URL を置き換える

これで、フォームの内容が登録したメールアドレスに届きます。

## 🚀 GitHub Pages での公開手順

1. このリポジトリを GitHub に push する
2. GitHub の **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」にし、ブランチ（例：`main`）とフォルダ `/ (root)` を選んで保存
4. 数分後、`https://<ユーザー名>.github.io/homepage/` で公開されます

### 独自ドメイン（kskac.jp）を割り当てる

1. **Settings → Pages → Custom domain** に `kskac.jp` と入力して保存
2. ドメイン管理会社の DNS で次を設定
   - `kskac.jp`（アペックス）→ A レコード4件：`185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`
   - `www.kskac.jp` → CNAME で `<ユーザー名>.github.io`
3. DNS 反映後、**Enforce HTTPS** にチェック

> ⚠️ 独自ドメイン設定後は github.io のプレビューが独自ドメインへリダイレクトされます。
> **DNS を切り替える準備が整ってから**設定してください。

## 🎨 アイコン（Font Awesome）

アイコンは外部から読み込まず、**サイトで使う22種類だけ**を抜き出して同梱しています
（`icons/kskac-icons.woff2` 約2.8KB／元は154KB）。
アイコンを追加・変更したら、次を実行してください。

```
python3 tools/build-icons.py
```

- 使えるアイコン名は `icons/src/css/all.css` にあるもの（Font Awesome Free 6.6.0 の solid）
- HTMLに `<i class="fa-solid fa-〇〇">` と書いてから上のコマンドを実行すると、
  そのアイコンが自動で収録されます。実行しないと**新しいアイコンは表示されません**
- `css/style.css` の中で `content: "\f0??"` と直接指定しているものも自動で拾います

ライセンス：Font Awesome Free（アイコン CC BY 4.0／フォント SIL OFL 1.1）。
原文は `icons/src/LICENSE.txt`。

## 📊 アクセス解析（Googleアナリティクス GA4）

- 測定ID：`G-EYJYJXQECM`（プロパティ名「kskac.com」）
- タグは全HTMLの `<head>` に直接書かれています。IDを変えるときは**全ファイルを一括置換**してください
- 計測している独自イベント
  - `generate_lead` … お問い合わせ送信完了（thanks.html を開いたとき）
  - `tel_click` … 電話番号リンクのタップ（GA4の拡張計測機能では数えられないため自前で送信）

### 自分（事務所）のアクセスを集計から外す

除外したい端末のブラウザで、次のURLを**一度だけ**開きます。

```
https://kskac.com/?noga=1     ← 除外する
https://kskac.com/?noga=0     ← 除外を解除する
```

画面下に確認メッセージが数秒出ます。設定はそのブラウザに保存され、以後どのページを見ても
計測されません。**端末ごと・ブラウザごと**に必要です（PCのChrome、iPhoneのSafari…）。
ブラウザの閲覧データを消すと設定も消えるため、その場合は開き直してください。
